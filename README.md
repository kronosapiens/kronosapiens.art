# kronosapiens.art
Artist portfolio website

## Development

The site is a Next.js app that builds its pages from the markdown in `materials/`.

- `pnpm install` installs dependencies.
- `pnpm dev` runs the site at http://localhost:3000.
- `pnpm build` builds the site, and `pnpm start` serves the build.
- `pnpm lint` runs ESLint.
